# 装修记账看板 Skill

一个帮助 AI 开发助手搭建和维护个人装修记账 Web 应用的 Skill。

**这是开发指导与验收规范，不是已经部署好的记账 App。** 使用者需要自行配置模型 API、数据库和部署账号。

## 包含什么

- 六大分类独立预算：硬装、电器、全屋智能、灯具、家具、其他。
- 实际支出总览，以及实际支出加未完成采购预算的计划预测。
- 装修采购、施工、安装和验收计划，支持日期与分类筛选。
- 多图 AI 识别：实际账单与未来计划分别处理，用户确认后才保存。
- 编辑计划时保留原编号，不重复入账，不改动关联实际支出。
- 云端版本核对、冲突处理、历史留档和本机备份。
- 数据安全与功能验收清单。

默认技术方案为 Vue 3、Tailwind CSS、Supabase、GitHub 和 Vercel，也可按项目要求调整。

## 使用

下载仓库 ZIP，解压后将目录重命名为 `build-renovation-ledger`，放入开发助手的 Skills 目录。Codex 默认目录为 `~/.codex/skills/`；自定义环境请使用其配置的 Skills 目录。

开始新对话后可输入：

```text
请使用 $build-renovation-ledger 开发一个支持预算管理、装修计划、AI识图和安全云同步的个人装修记账看板。
```

已有项目可这样调用：

```text
请使用 $build-renovation-ledger 为现有装修计划增加 AI 识图，识别结果经我确认后更新原计划，不新增重复记录，不改变实际支出。
```

其他支持文件式 Skill 的开发助手，可按其安装方式加载本目录；也可直接阅读 SKILL.md 及引用文档。

## 配置与数据

本仓库不包含个人账本、服务凭证或任何可直接访问的业务数据库配置。模型密钥应放在服务端，私人账本应采用身份验证和数据库权限隔离。

Skill 提供实现要求，不保证生成应用已通过测试或部署；实际项目需要按清单验证。历史备份只能恢复已被保存的版本，不能补回从未留档的历史数据。
